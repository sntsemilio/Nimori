# Seguridad

Nimori está en desarrollo activo y no tiene una versión estable. El código actual no ejecuta modelos ni agentes, pero las próximas versiones incorporarán descargas, procesos locales y archivos externos.

## Versiones con soporte

| Versión | Soporte |
|---|---|
| Rama `main` | Correcciones durante el desarrollo |
| Versiones anteriores | Sin soporte garantizado |

## Reportar una vulnerabilidad

No publiques detalles explotables en un issue. Usa el formulario privado **Security → Report a vulnerability** del repositorio para describir el impacto, los pasos de reproducción y cualquier mitigación conocida.

El proyecto todavía no establece un tiempo de respuesta garantizado. El reporte se evaluará antes de publicar detalles o una corrección.

Los fallos funcionales que no tengan impacto de seguridad pueden enviarse mediante la plantilla de bug.
